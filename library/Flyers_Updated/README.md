# Flyers_Updated

Upload new or updated flyers here. They appear in the app's **Teachings (flyers)** tile
within a few minutes, with no app update needed.

**Best:** one folder per language, named in English or in the language's own script:
`Urdu/`, `Hindi/`, `اردو/`, `ಕನ್ನಡ/` …

**Also fine:** a file placed directly here, if its name mentions the language,
for example `Urdu flyers.pdf` or `Tamil flyer 3.jpg`.

- Images (JPG, PNG) become one flyer each, ordered by the number in the file name.
- A **PDF** becomes one flyer per page, rendered at print quality, so one PDF per language is enough.
- GitHub's upload page takes files up to 25 MB each.

### Files over 25 MB
Attach them to the **flyers** release instead (up to 2 GB per file):
1. Open https://github.com/dh-app/DH/releases and click the **flyers** release → **Edit**
   (the first time: **Draft a new release**, type `flyers` as the tag, choose
   **Create new tag**, give it the title `Flyers`).
2. Drag the files into **Attach binaries** and wait for every upload to finish.
3. Click **Update release** (the first time: **Publish release**).

Name each file after its language, e.g. `Nabi ur Rahmah Urdu.pdf`. The catalogue
rebuilds on its own; each PDF page becomes a flyer, replacing that language's
website copies.

### Uploading into a language folder on GitHub
1. Open this folder and choose **Add file → Upload files**.
2. Drag in the files. To make a new language folder, drag in the **folder itself**
   (for example a folder called `Urdu` from your computer). GitHub keeps its name.
3. Click **Commit changes**.
